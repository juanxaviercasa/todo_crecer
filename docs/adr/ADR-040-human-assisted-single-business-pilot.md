# ADR-040: Piloto asistido con un único negocio

**Estado:** Aceptado · **Fecha:** 2026-10-02

La fase 32 limita el aprendizaje a un candidato y exige intervención humana para iniciar la conversación. Se selecciona el expediente de Silvana Verano por representar una operación individual adecuada para validar confianza y acompañamiento. Esto no implica relación comercial ni consentimiento.

El sistema prepara el guion, FAQ, consentimiento, entrevista, estructura de activos y ensayo. La salida permanece bloqueada hasta verificar un destino real y aprobar el texto exacto. Aun entonces, el sistema entrega el paquete a una persona; no envía automáticamente.
