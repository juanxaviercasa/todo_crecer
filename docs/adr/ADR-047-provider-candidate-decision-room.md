# ADR-047: Sala de incorporación y decisión de proveedores

**Estado:** Aceptado · **Fecha:** 2026-10-03

La fase 39 permite abrir expedientes antes de conocer candidatos reales, siempre que cada dato sintético o pendiente permanezca marcado como placeholder. Compleción estructural y evidencia real se miden por separado.

Legal, seguridad, finanzas y compras revisan dominios independientes. El software prepara y bloquea; una persona autorizada realiza cualquier selección final únicamente con evidencia real completa.
