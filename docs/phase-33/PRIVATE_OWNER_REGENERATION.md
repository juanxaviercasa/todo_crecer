# Fase 33 · Sala privada del propietario

La sala cubre identidad, BusinessTruth, activos, derechos, regeneración del sitio, comparación antes/después, rondas de cambios y aceptación. El ensayo usa una propietaria y una marca sintéticas, claramente separadas del candidato real.

Ejecutar con `npm run build && npm run start:owner-room` y abrir http://127.0.0.1:4207/.
