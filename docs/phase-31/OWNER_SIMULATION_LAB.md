# Fase 31 · Laboratorio de propietarios sintéticos

El laboratorio reproduce el viaje completo sin contactar a ningún negocio. Cinco gemelos sintéticos cubren una aceptación, falta de respuesta, preguntas, activos incompletos y rechazo.

Ejecutar con `npm run build && npm run start:simulation` y abrir http://127.0.0.1:4205/.
