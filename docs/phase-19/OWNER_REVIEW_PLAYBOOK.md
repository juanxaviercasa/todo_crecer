# Guía de revisión con el propietario

## Preparación

Entregar una URL privada y temporal, la lista de páginas y un resumen de hechos usados. Evitar presentar el demo como publicado o como resultado definitivo.

## Sesión recomendada

1. Confirmar identidad, público y oferta.
2. Recorrer la home y la principal página de conversión.
3. Revisar cada fotografía y su derecho de uso.
4. Leer llamadas a la acción y datos de contacto.
5. Revisar móvil, accesibilidad y velocidad percibida.
6. Explicar privacidad, retención y tratamiento de contactos.
7. Confirmar dominio, ventana de lanzamiento y rollback.

## Registro de decisiones

El propietario puede aceptar, solicitar cambios o declinar. “Aceptar” exige confirmar autoridad, hechos, derechos de activos, contacto público, dominio y aviso de privacidad. Este registro valida el flujo del producto; no sustituye contratos ni una solución de firma electrónica.

## Después de la sesión

Una solicitud de cambio devuelve el expediente a borrador. Las aprobaciones previas no se reutilizan porque apuntan al hash anterior.
