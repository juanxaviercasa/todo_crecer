Existe actualmente un ecosistema formado por tres dominios principales.

Es un directorio de negocios y profesionales de Lima.

Actualmente contiene aproximadamente:

- 38 categorías.
- Alrededor de 3.800 negocios/profesionales.

# 4. PRINCIPIO OPERATIVO

El sistema debe diseñarse bajo el principio:

## AUTOMATION FIRST — HUMAN BY EXCEPTION

Los humanos no deberían participar rutinariamente en tareas que puedan convertirse en procesos estructurados.

El flujo normal debe ejecutarse automáticamente.

Los humanos deberían intervenir principalmente cuando exista:

- baja confianza;
- información contradictoria;
- excepción comercial;
- fallo técnico;
- reclamación;
- riesgo legal;
- problema de seguridad;
- cliente premium;
- personalización especial;
- decisión que requiera criterio humano.

Diseñar un sistema de:

- confidence scores;
- automatic approval;
- manual review;
- blocked states;
- retry;
- escalation;
- exception queue.

- automatización;
- resiliencia;
- calidad;
- conversión;
- velocidad;
- modularidad;
- escalabilidad;
- bajo coste inicial;
- bajo coste marginal;
- observabilidad;
- mantenibilidad.

Y minimizar:

- trabajo manual;
- deuda técnica;
- dependencia de proveedores;
- errores de IA;
- duplicación;
- infraestructura innecesaria;
- costes prematuros;
- operaciones difíciles.

Cuando haya conflicto entre “tecnología interesante” y “negocio rentable”, prioriza el negocio rentable.

Tu misión final es diseñar **la máquina empresarial completa**, no solamente la tecnología.
