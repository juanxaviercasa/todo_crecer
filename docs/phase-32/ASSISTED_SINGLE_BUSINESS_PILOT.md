# Fase 32 · Piloto asistido con un único negocio

El piloto prepara una conversación completa para un solo candidato. Incluye guion, preguntas frecuentes, consentimiento privado, entrevista, carpeta de activos, ensayo y gate de salida.

Estado real: candidato seleccionado, seis artefactos listos y ensayo aprobado. Destino y autorización pendientes. Cero mensajes y cero publicaciones.

Ejecutar con `npm run build && npm run start:assisted-pilot` y abrir http://127.0.0.1:4206/.
