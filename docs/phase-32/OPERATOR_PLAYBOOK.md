# Guía del operador

1. Confirmar que el destinatario representa al negocio.
2. Registrar únicamente el canal enmascarado y el método de verificación.
3. Leer el guion exacto y resolver preguntas con el FAQ.
4. Escalar precio, condiciones, privacidad o asuntos legales.
5. Si rechaza, agradecer y cerrar sin seguimiento.
6. Si acepta, emitir el consentimiento privado y continuar con entrevista y activos.
