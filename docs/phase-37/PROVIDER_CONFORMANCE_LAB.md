# Fase 37 · Laboratorio de conformidad

El laboratorio evalúa residencia, cifrado, lifecycle, rotación, observabilidad y coste con transportes falsos. Produce scorecards comparables, selecciona un candidato elegible y sella un informe sin conexiones externas.

Ejecutar con `npm run build && npm run start:provider-lab` y abrir http://127.0.0.1:4211/.
