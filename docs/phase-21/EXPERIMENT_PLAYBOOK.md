# Playbook de experimentos

1. Escribir una hipótesis concreta y una métrica primaria.
2. Definir control, tratamiento y asignación total de 100%.
3. Fijar muestra mínima y uplift antes de iniciar.
4. Definir límites de LCP, INP, CLS e incidentes.
5. Obtener aprobación de una persona distinta del creador.
6. Registrar una observación agregada por variante.
7. Evaluar primero guardrails, después muestra y finalmente diferencia.
8. Documentar el resultado sin afirmar causalidad fuera del alcance del ensayo.

Un guardrail fallido detiene el aprendizaje aunque la conversión aparente sea mayor.
