# Taxonomía de eventos

## Eventos admitidos

- `page_view`
- `cta_view`
- `cta_click`
- `form_start`
- `form_submit_accepted`
- `lead_qualified`
- `appointment_requested`

## Dimensiones admitidas

Tenant, sitio, arquetipo, ruta agrupada, clase de dispositivo, modo de consentimiento, bucket efímero y variante del experimento.

## Prohibiciones

No se admiten nombres, correos, teléfonos, IP, user agent, URL completa, query, texto escrito, ubicación precisa ni identificadores publicitarios.

La interacción analítica requiere consentimiento `analytics`. El modo `essential` solo conserva señales operativas imprescindibles ya aceptadas.
