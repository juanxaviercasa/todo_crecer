# Aprendizaje para recetas verticales

Un ganador puede originar una propuesta, nunca un cambio automático. La propuesta conserva resultado, observaciones, sitio fuente, arquetipo, componente, cambio sugerido y riesgo.

La aprobación independiente significa que el patrón merece otro piloto controlado. No significa que sea universal ni que deba desplegarse a toda la flota.

Resultados insuficientes, equivalentes o con guardrails fallidos no generan propuestas accionables.
