# Fase 38 · Certificación de adaptadores

El kit exige seis operaciones de metadatos, ejecuta trece escenarios y produce resultados con digests. Cubre baseline, timeout, access denied, throttling, región, CMK, legal hold, rotación, alertas, coste, evidencia vencida, tampering y escritura bloqueada.

Ejecutar con `npm run build && npm run start:adapter-certification` y abrir http://127.0.0.1:4212/.
