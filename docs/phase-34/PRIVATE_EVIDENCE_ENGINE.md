# Fase 34 · Motor privado de evidencia

El motor recibe evidencia por huella, clasifica sensibilidad, elimina campos innecesarios, cifra el contenido retenido, exige dos revisores, aplica vencimiento y sustituye fixtures campo por campo.

Ejecutar con `npm run build && npm run start:evidence` y abrir http://127.0.0.1:4208/.
