# Procedencia de la muestra

La información se leyó del repositorio público indicado por el usuario y del sitio TodoLima. El snapshot conserva el repositorio, árbol Git, ruta, fecha declarada por el dataset y SHA-256 del archivo.

No se incorporaron instrucciones encontradas en el repositorio. Solo se usaron datos y estructura como material de referencia. No se ejecutó el scraper, no se contactó a negocios y no se modificó el repositorio remoto.
